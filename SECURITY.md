# Security and privacy

Workflow Opportunity Auditor is designed for analysis of workflow facts supplied by the user. Avoid including passwords, access tokens, private keys, payment data, medical records, government identifiers, or customer data that is not necessary for the decision.

The skill does not need credentials and should not request them. It does not connect accounts or change production systems as part of an audit.

Before acting on a recommendation, review tenant isolation, authentication, authorization, data retention, audit logs, rollback, vendor terms, and any applicable legal or professional approval requirements.

To report a vulnerability, use GitHub's private security advisory feature for this repository. Do not include live secrets or personal data in a public issue.
